一、我們要一起做出什麼產品？

一個部署在 GitHub Pages、專為台灣本島與離島自由行設計的網頁規劃工具。針對目前台灣常見旅遊工具常忽略的現場問題，集中解決以下 5 件實戰大事：

  1. 同團混搭身分折價 ＋ 個別分帳（AA 結算）：不用填姓名或身分證，只要點選同團有幾位大專生、65 歲以上長輩、3–12 歲孩童、未滿 3 歲幼兒、身心障礙與陪伴者、或澎金馬設籍住民，系統先幫全團算出高鐵早鳥／大學生／敬老／愛心／離島住民與免稅機票，再拆出每種身分這趟應付多少錢（交通各算各的，房費與租車均攤）。
  2. 補齊「出發地」＋ 住宿平假日／連假係數：從台北、台中還是高雄出發，決定的高鐵站與離島機場／港口完全不同；系統同時結合「政府行政機關辦公日曆表」，計算週五六與連假住宿溢價，主動提示「往前或往後挪一天改平日大概能省多少」。
  3. 台灣本島＋離島多元運具分段銜接：高鐵、台鐵、國內線飛機與公營船班透過每日預抓＋共用快取取得真實班表與票價，民營小離島航線（小琉球、綠島、蘭嶼）採雙層備援與官網即時確認連結；島內／市區（台灣好行、租汽車、租機車、YouBike）依門到門距離與緩衝務實估算。
  4. 海氣象連動雨備 ＋ 零元台灣地圖：串接中央氣象署潮汐與海域波浪預報，浪高風大提前亮黃紅燈並自動附掛室內雨備；結果頁直接內嵌內政部國土測繪中心圖磚（WMTS）＋ Leaflet 顯示每日編號路線，用 44px 按鈕就能一鍵換順路點、上下調序或切雨備。
  5. 免登入完整外帶包（帶出門沒網路也能看）：支援 PWA 離線快取、一鍵開出當日 Google Maps 多點導航路線、匯出 .ics 進手機行事曆提醒搭車搭船、乾淨列印版面，以及靠 Firestore Spark 產出「免登入唯讀分享短連結（旅伴點開還能一鍵複製成自己的副本微調）」。

三、升級版系統架構（Option C v2：避開 TDX 5 次/分限流）

關鍵架構修正：TDX 免費一般會員全帳號限流為 5 次／分鐘（取 Token 限 20 次／分鐘），且 Cloudflare Workers 記憶體變數不會跨節點共享。因此改採 「靜態預抓為主 ＋ Cloudflare KV 跨節點共用快取」：雙鐵班表、季班表、觀光 V2.1 與政府辦公日曆表全由 GitHub Actions 每日低速（請求間隔 ≥ 15 秒）預抓進 Repo；Worker 僅以 KV 共用快取處理 TDX Token（4–6 小時快取）、海象預報（3 小時快取）與當日開停航（15 分鐘快取）。

五、完整雙向資料合約藍圖（schema/trip.ts）

為了讓優惠精算師與介面設計師在分開開發時 100% 對得起來，這次把輸入合約（TripInput）與輸出合約（TripPlanResult）一次定齊：

TypeScript 合約藍圖 (schema/trip.ts)
export type OriginRegion =
  | 'taipei_keelung' | 'taoyuan_hsinchu_miaoli' | 'taichung_changhua_nantou'
  | 'chiayi_yunlin' | 'tainan' | 'kaohsiung' | 'pingtung' | 'yilan_hualien_taitung';

export type RegionCode =
  | 'penghu' | 'xiaoliuqiu' | 'taipei' | 'tainan' | 'hualien_taitung'
  | 'kinmen' | 'matsu' | 'green_island' | 'orchid_island' | 'other_tw';

export type IdentityKey =
  | 'adult'
  | 'collegeStudent'
  | 'senior65Plus'
  | 'child3To12'
  | 'infantUnder3'
  | 'disabledWithCompanion';

export type IdentityCounts = Record<IdentityKey, number> & {
  offshoreResident: boolean;
};

export type TravelPassOwned = {
  seniorCardCounty?: string;
  tpassRegion?: 'north' | 'central' | 'south' | 'east' | 'none';
};

export type TransportPreference =
  | 'hsr' | 'tra' | 'domestic_air' | 'ferry'
  | 'taiwan_tourist_shuttle' | 'rental_car' | 'scooter' | 'youbike';

export type LodgingTier = 'budget' | 'standard' | 'premium' | 'none';

export type TripInput = {
  origin: OriginRegion;
  destination: RegionCode;
  startDate: string; // YYYY-MM-DD
  days: number;
  budgetPerPersonTwd: number;
  lodgingTier: LodgingTier;
  roomCount?: number;
  group: IdentityCounts;
  passes: TravelPassOwned;
  preferredTransport: TransportPreference[];
  pace: 'relaxed' | 'balanced' | 'packed';
  avoidRainOutdoor?: boolean;
};

export type SeaRiskLevel = 'green' | 'amber' | 'red';

export type TransportLeg = {
  mode: TransportPreference;
  from: string;
  to: string;
  departureTime?: string;
  arrivalTime?: string;
  estimatedMinutes: number;
  source: 'tdx_live' | 'tdx_static' | 'ferry_fallback' | 'distance_estimate';
  sourceUrl?: string;
  groupTotalFareTwd: number;
  discountNotes: string[];
  seaRisk?: { level: SeaRiskLevel; waveHeightM?: number; warning?: string };
};

export type CuratedSpot = {
  id: string;
  region: RegionCode;
  name: string;
  category: 'sightseeing' | 'food' | 'indoor_backup' | 'lodging';
  lat: number;
  lng: number;
  stayMinutes: number;
  closedDays: number[]; // 0=週日 ~ 6=週六
  isIndoor: boolean;
  wheelchairAndStrollerFriendly: boolean;
  estimatedCostTwd: number;
  source: 'curated' | 'tdx_v2';
  tips?: string;
};

export type DayStop = {
  stopId: string;
  spot: CuratedSpot;
  startTime: string; // HH:MM
  endTime: string;   // HH:MM
  isUsingBackup?: boolean;
  backupSpot?: CuratedSpot;
  googleMapsUrl: string;
};

export type DayPlan = {
  dayIndex: number;
  date: string;
  weekday: number;
  isHolidayOrWeekend: boolean;
  seaRisk?: { level: SeaRiskLevel; waveHeightM?: number; warning?: string };
  legs: TransportLeg[];
  stops: DayStop[];
  googleMapsRouteUrl: string;
};

export type IdentityCostShare = {
  identity: IdentityKey;
  count: number;
  transportPerPersonTwd: number;
  lodgingPerPersonTwd: number;
  activityPerPersonTwd: number;
  totalPerPersonTwd: number;
  appliedDiscounts: string[];
};

export type BudgetBreakdown = {
  originalTotalTwd: number;
  discountedTotalTwd: number;
  savedTotalTwd: number;
  transportTwd: number;
  lodgingTwd: number;
  activityAndFoodTwd: number;
  isOverBudget: boolean;
  weekdayShiftSavingHint?: {
    suggestedStartDate: string;
    estimatedSaveTwd: number;
    reason: string;
  };
  perIdentitySplit: IdentityCostShare[];
};

export type ReviewWarning = {
  severity: 'red' | 'amber' | 'info';
  code: 'CLOSED_DAY' | 'TIGHT_TRANSFER' | 'OVER_BUDGET' | 'SEA_RISK' | 'HOLIDAY_SURGE';
  message: string;
  dayIndex?: number;
};

export type TripPlanResult = {
  input: TripInput;
  days: DayPlan[];
  budget: BudgetBreakdown;
  reviewWarnings: ReviewWarning[];
  aiSummary?: string;
  modeUsed: 'ai_assisted' | 'rule_only';
  generatedAt: string;
};

六、共同協作默契與 4 人多 AI 協作鐵律

  1. 各自守住主場資料夾（CODEOWNERS 邊界）：
    • 架構師顧 schema/、.github/、根目錄設定檔與主機閘道。
    • 路線情報員顧 services/ 與 data/。
    • 優惠精算師顧 engine/。
    • 介面設計師顧 src/。
    • 共用資料夾 data/curated/ 僅修改各自認領的區域檔案。少欄位先由架構師對齊再改 schema/trip.ts，禁止私下各自加欄位。
  2. 根目錄依賴鎖定（禁止自行安裝套件）：
    • 根目錄 package.json 與 package-lock.json 已預裝常用套件（leaflet、react-leaflet、zod、lucide-react、vite-plugin-pwa 等），並由 .github/CODEOWNERS 鎖定由架構師維護。
    • 非架構師分支禁止自行執行 npm install 改動依賴檔案；若開發時發現缺少必要套件，請告知架構師統一更新至 main。
  3. 禁止直推 main，啟用 protect-main 分支保護：
    • 倉庫已啟用 GitHub 分支保護規則 protect-main（需 1 位審核、需 Code Owners 審核、需通過 CI 檢查、禁止 force push）。
    • 所有成員（包含各自的 AI 夥伴）嚴禁在 main 直接提交或推送，一律建立 feat/<角色>-<主題> 分支進行開發。
    • 使用者或 AI 準備儲存/推送時，可透過 /backup 技能或標準 Git 流程自動切分支並建立 Pull Request。
  4. 推送前必跑本機三項檢查：
    • 任何分支推送前必須於本機執行並通過：
  5. npm run typecheck（TypeScript 型別檢查 0 錯誤）
  6. npx vitest run（單元測試全數通過）
  7. npm run build（Vite 建置成功）
    • 以 git diff --stat origin/main 確認未越界修改其他成員的主場目錄或共用 schema/。
  8. 先拿同一份 mockTripData.ts 平行開工：合約定案當天，三條開發線同時開工，彼此完全不用互相等待。
